A few things
worth knowing

What is a physics twin?+

A model of a real energy asset, built around how it physically works. Laplace compares that model with measured performance to help identify losses and test decisions.

What do we need to get started?+

Start with one site, its capacity, and the operating problem you want to solve. Share the generation technology, available SCADA and meter data, and operating history. For batteries, include MW/MWh ratings. The data requirements are tailored to each asset. We agree data access during scoping.

Does Laplace control our equipment?+

The current demo uses recorded data and simulated actions. We start pilots with read-only data access and operator-reviewed recommendations. Battery scheduling is in development; autonomous plant control is not part of the current demo.
